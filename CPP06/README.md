# CPP Module 06

_This project has been created as part of the 42 curriculum by nfakih._

## Description

CPP Module 06 focuses on static cast for scalar conversion, serialization using uinptr, and references and pointers using dynamic cast and try catch statements.

**Key concepts:**
- Exception handling (try catch)
- Static Cast
- Dynamic cast

## Instructions

Clone the repo using
```bash
git clone ..
```
Then compile within each directory using
```bash
make        # Compile the program
make clean  # Remove object files
make fclean # Remove object files and executable
make re     # Recompile from scratch
```
And lastly run the executable file
```bash
./file_name
```

### Project Structure

#### Exercise 00: Scalar Converter
Create a `Scalar Converter` class with:
- **Private Methods:**
  - Functions converting each datatype
- **Public Methods:**
  - Convert function that handles all conversions

#### Exercise 01: Serializer
Create a `Serializer` class with:
- **Methods:**
	-Serialize and Deserialize

#### Exercise 02: Base
Create A base class and A, B, C classes.
These all inherit the base class.
